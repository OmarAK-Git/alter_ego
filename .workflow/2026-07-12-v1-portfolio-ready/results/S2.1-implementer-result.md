# S2.1 implementer result

## Summary

Added deterministic collision/split fixture prefixes to the entity resolver, a shared low-confidence threshold, and scorer wiring to emit the `low_resolution_confidence` decision flag when `resolution_confidence` is below that threshold.

## Threshold

| Constant | Value | Meaning |
|---|---|---|
| `LOW_RESOLUTION_THRESHOLD` | **0.75** | Confidence at or above this is treated as high resolution; below triggers `low_resolution_confidence` |
| `COLLISION_SPLIT_CONFIDENCE` | **0.3** | Confidence assigned to collision and split fixtures |

## Fixture formats

| Pattern | Example | Resolves to | Confidence |
|---|---|---|---|
| `collide::<canonical>::<alias>` | `collide::user_123::alias_a` | `user_123` / `human` | 0.3 |
| `split::<ref>` | `split::user_456` | `user_456` / `human` | 0.3 |
| `user_*` / `svc_*` | `user_789`, `svc_101` | same id / typed | 1.0 |

## Files changed

| File | Rationale |
|---|---|
| `worker/resolver.py` | Added `LOW_RESOLUTION_THRESHOLD`, collision/split fixture parsing, and low-confidence assignment |
| `worker/scorer.py` | Emit `low_resolution_confidence` flag when `resolution_confidence < LOW_RESOLUTION_THRESHOLD` |
| `tests/worker/test_resolution_confidence_flags.py` | Collision, split, happy-path, and scorer flag tests |
