## Implementation notes

- **Shared image:** `alter_ego:latest` built once; `web` / `worker` / `batch` differ only by `command:`.
- **web:** `alembic upgrade head` then `uvicorn web.api:app --host 0.0.0.0 --port 8000`; `API_KEY` defaults to `dev-key`.
- **worker:** 5 s polling loop — `python -m worker.resolver` then `process_unscored_events()` (scores + records via existing modules).
- **batch:** `sleep infinity` idle container; profile build, synthetic, and eval harness documented as `docker compose exec` one-shots.
- **postgres:** `ankane/pgvector:latest` with healthcheck; service renamed from legacy `db` to `postgres` per SPEC §4.4.
- **v1 constraints documented:** local-only, no TLS/ingress/external auth; kind/k8s and Terraform deferred to later packets.
