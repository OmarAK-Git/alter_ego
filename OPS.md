# Operational Guide

Generated by the ultimate-agentic-workflow skill. Keep this file under 60 lines; status and progress belong in the active plan or `.workflow/`.

## Build And Run

- Install: `pip install -e ".[dev]"`
- Run API: `uvicorn web.api:app --reload`
- DB: `docker compose up -d` (Postgres + pgvector) or sqlite via `DATABASE_URL`

## Validation

- Test: `pytest -v --tb=short`
- Lint: `ruff check .`
- Typecheck: `mypy .`
- Migrate: `alembic upgrade head`

## Operational Notes

- Prefer `config/scoring_config.yaml` + `docs/calibration_final_metrics.json` over README/CLAUDE narrative for thresholds and scenario recall claims.
- Embeddings are deterministic char 3-gram SHA-256 hashes → **128-d** unit-norm vectors (`alter-ego-ngram-v1`, `worker/vectorizer.py`), not 768-d BERT / nomic; Alembic `nomic-embed-text` default is S1.4 debt. `drift_threshold` is **5.0** in scoring_config (not 1.0).
- Cohort priors are profile-embedded (`features["cohort_data"]`) only in v1; independent versioned cohort artifacts deferred (S2.5 / S5.11).
- Profile lifecycle states (dormant/reactivated/onboarding/role_transition) deferred in v1 (S2.7); alert workflow badges ≠ profile lifecycle.
- Calendar dual-score and telemetry-gap two-tier deferred in v1 (S4.6); single `score` field; staleness halt only for profile freshness.
- Do not commit local `alter_ego_calibrate_v*.db`, `alter_ego_eval.db`, or `__pycache__` experiment churn.
- **Standing rule:** never change feature weights/thresholds without a recorded full sweep + governance (`docs/scoring-config-governance-s3.md` pattern or `ConfigStore.save_config` with author/reason).
- **S3 attestation:** knobs unchanged — `scoring_config` v2.2 @ `anomaly_threshold=45` through S3.1 re-sweep; PR-curve thr=55 diagnostic **not applied** (see `docs/scoring-config-governance-s3.md`).
