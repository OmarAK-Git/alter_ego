# Product Context

## Why it exists

Signature/rule detectors miss novel misuse of legitimate credentials. ALTER_EGO learns per-entity baselines and flags deviations with explainable feature contributions.

## How it should feel

- Every score is reproducible from `(event, profile_version, config_version)`.
- Analysts see raw score primacy, confidence separation, and grounded explanations.
- Containment is simulated (queue), not real account disablement.

## Users

Single-operator / portfolio demo: developer runs synthetic eval + local triage UI.
